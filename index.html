Registrar operación

Para una tenencia inicial, el precio es tu costo unitario con gastos incluidos o el valor de referencia elegido. La fecha y el CCL deben corresponder a esa base. Cargá un lote por compra si conocés costos históricos distintos. Para Spot, cantidad bruta antes de comisión; una compra con USDT/USDC descuenta su saldo, y una venta lo incrementa. Cargá primero el saldo inicial de esas monedas y de BNB si lo usás para comisiones.

El TC convierte el flujo de cada fecha. Los gastos manuales reemplazan la tarifa. Usá el mismo ticker y base de cotización para comprar y vender un instrumento.
